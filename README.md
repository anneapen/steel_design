# Steel Design Using IS 800:2007
A Python-based repository for the analysis and design of structural steel members and connections in accordance with IS 800:2007 – General Construction in Steel: Code of Practice.
The aim of this project is to translate commonly used steel design calculations into simple, transparent, and reusable Python functions for students, engineers, and researchers working with Indian Standards.

# Features:
The repository is being developed to cover major steel design checks including:
-Material properties and design strengths
-Bolted connections
-Welded connections
-Tension members
-Compression members
-Beams and flexural members
-Members subjected to combined forces
-Section property calculations
-Design strength calculations
-Serviceability and other relevant limit-state checks

Calculations follow the Limit State Method (LSM) provisions of IS 800:2007 wherever applicable.
